# নিউজ ফটোকার্ড মেকার (Photocard Maker)

ভাইরাল বাংলা নিউজ স্টাইলের ফটোকার্ড তৈরির মোবাইল-ফার্স্ট PWA।  
**Live:** https://mdrobiny.github.io/photocard-maker/

## Features
- ৮টি টেমপ্লেট: ব্রেকিং, ক্লাসিক, ডার্ক গ্রেডিয়েন্ট, কোট, স্পোর্টস, শোক, উদযাপন, মিনিমাল
- বাংলা ফন্ট (Hind Siliguri, Noto Serif Bengali, Tiro Bangla, Baloo Da 2, Anek Bangla)
- সাইজ: 1080×1080, 1080×1350, 1080×1920, 1200×630
- ফটো ক্রপ/ড্র্যাগ/জুম, অ্যাকসেন্ট কালার, `*হাইলাইট*` শব্দ
- PNG এক্সপোর্ট + Web Share API
- Installable PWA · localStorage · ওয়াটারমার্ক টগল

## Brand
Default brand: **Robin Cents** — নিজস্ব ব্র্যান্ডিং; কোনো নিউজ আউটলেটের লোগো/নাম কপি করা হয়নি।
